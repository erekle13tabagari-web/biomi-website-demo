# ბიომი / Biomi — ვებსაიტი

HVAC + წყალმომარაგების კომპანიის ვებსაიტი. სტატიკური HTML/CSS/JS (build-ის გარეშე).

## სტრუქტურა
```
index.html              — მთავარი გვერდი
assets/
  css/style.css         — დიზაინ-სისტემა და ყველა კომპონენტი
  js/main.js            — ჰედერი, მობილური მენიუ, scroll-reveal
  img/logo-mark.svg     — ლოგოს ნიშანი (currentColor — ნებისმიერ ფონზე)
.claude/                — preview სერვერი (serve.ps1, launch.json) — დეველოპმენტისთვის
```

## ბრენდი (Brand Book-იდან)
| ელემენტი | მნიშვნელობა |
|---|---|
| Navy (მთავარი) | `#252633` |
| Gold (აქცენტი) | `#E8BA7C` |
| Gray | `#585B5B` |
| Light gray | `#D3D3D3` |
| ფონტი | FiraGo (300/400/500/700) + Noto Sans Georgian fallback |

ფერები განსაზღვრულია CSS ცვლადებად `:root`-ში (`assets/css/style.css`) — შესაცვლელად ერთ ადგილს არედაქტირებ.

## ვიზუალური ენა (layout-ის მიხედვით)
- **ჰედერი:** თეთრი ზოლი, **ცენტრში ლოგო**, მენიუ გაყოფილია (მარცხნივ 4 / მარჯვნივ 4), დროშის ენის dropdown + ძიება.
- **Hero:** სრულ-სიგანის **ფოტო-კარუსელი** ისრებითა და კაპშენით ქვედა-მარცხენა კუთხეში.
- **კომპანიის შესახებ:** ტექსტი მარცხნივ, ფოტო მარჯვნივ, თეთრ ფონზე.
- ზოგადი სტილი: მინიმალისტური, თეთრი, ფოტო-ორიენტირებული; ოქროსფერი მხოლოდ აქცენტად.

## ნამდვილი ფოტოების ჩასმა / შეცვლა
- **Hero (უსასრულო კარუსელი):** მართკუთხა ბარათები `.hero__card`-ებია `index.html`-ში; თითო `style="background-image:url('assets/img/...')"`-ით. ბარათების ნაკრები **გადუბლირებულია** (2 იდენტური ნახევარი) უწყვეტი loop-ისთვის — ფოტოს დამატება/შეცვლისას ორივე ნახევარში გააკეთე. სიჩქარე: `.hero__track { animation: heroMarquee 45s ... }`. hover-ზე ჩერდება.
- **About / News / Products / Projects:** ფოტოები `assets/img/`-შია (`about.avif`, `prod-*.jpg`, `hero-*`). შესაცვლელად ჩაანაცვლე ფაილები ან `<img>`/`background-image`.

## გაშვება
ნებისმიერი სტატიკური სერვერი. ამ პროექტში preview-სთვის გამოყენებულია PowerShell-ის სერვერი:
`http://localhost:8123` (`.claude/serve.ps1`). ან უბრალოდ გახსენი `index.html` ბრაუზერში.
